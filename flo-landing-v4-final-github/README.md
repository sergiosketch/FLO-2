## Reemplazo en GitHub
Sube el contenido de esta carpeta a la raíz del repositorio y reemplaza:
- index.html
- README.md
- assets/styles.css
- assets/main.js
- assets/images/*

Luego haz commit en `main`. Netlify debe desplegar automáticamente.

## Importante
Las imágenes son archivos independientes del texto. Esto permite cambiar fotografías posteriormente sin reconstruir el HTML.
